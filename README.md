# hackaton_SCZ

Sitio público del proyecto: **https://asosab.github.io/hackaton_SCZ**

Estático, sin build. GitHub Pages sirve la rama `main` desde la raíz.

- `index.html` — portada del proyecto y sección de equipo.
- `diario/` — bitácora de avance; una entrada por día (`YYYY-MM-DD.html`)
  enlazada desde `diario/index.html`.
- `assets/` — css e imágenes.

El material de trabajo (insumos, contactos, vault de conocimiento) vive en el
repo privado `hackaton_SCZ_privado`.
